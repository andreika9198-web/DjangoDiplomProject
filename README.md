# Проект умного полива

Данный проект включает в себя 4 основных раздела:
1) Работа с растениями
2) Мониторинг датчиков
3) Управление устройством
4) Аналитика

Виртуальное окружение используемое для проекта: venv
1) После настройки виртуального окружения установите из файла requirements.txt
```bash
  pip install -r requirements.txt
```
2) Заполните файл env. согласно .env_sample
3) Создайте миграции при помощи
```bash
  python manage.py makemigrations
```
4) Приведите миграции при помощи
```bash
  python manage.py migrate
```
5) Выполните команду для создания пользователей с разным уровнем доступа
```bash
  python manage.py ccsu
```
6) Запустите проект при помощи 
```bash
  python manage.py runserver 0.0.0.0:8000
```
Модели используемые в проекте:
Plant с полями:
- name - Название растения; 
- min_humidity - Нижний порог влажности %; 
- max_humidity - Верхний порог влажности %; 
- is_active - Активность; 
- owner - Владелец; 
- created_at - Дата создания

SensorData с полями:
- plant - Растение; 
- humidity - Влажность почвы %; 
- temperature - Температура °C; 
- created_at - Дата создания

WateringLog с полями:
- plant - Растение; 
- started_at - Дата начала; 
- duration - Длительность (секунд); 
- source - Источник (auto/manual/vk); 
- success - Успешно; 
- comment - Комментарий

DeviceState с полями:
- automatic - Автоматический режим;
- pump - Насос включён;
- light - Свет включён;
- updated_at - Дата обновления

CameraState с полями:
- is_on - Камера включена; 
- updated_at - Дата обновления

Device с полями:
- name - Название; 
- device_id - ID устройства; 
- plant - Привязанное растение; 
- is_active - Активность; 
- last_seen - Последний сигнал; 
- created_at - Дата создания

User с полями:
- email - Email;
- role - Роль;
- first_name - Имя;
- last_name - Фамилия;
- avatar - Аватар;
- phone - Телефон;
- vk_id - ID ВКонтакте;
- is_active - Активность;
- verification_code - Код восстановления

Разрешения (Ролевая модель):
- Смотреть списки растений, датчиков и аналитики могут все авторизованные пользователи
- Смотреть подробную информацию о растении могут все пользователи
- Создавать, изменять, удалять карточку растения могут только владелец или администратор
- Модератор может управлять растениями всех пользователей
- Администратор имеет полный доступ ко всем разделам

Пагинация
- Реализована пагинация: 3 растений на 1 страницу

Дополнительный функционал:
- Автоматический полив с гистерезисом (включение при влажности < 30%, выключение при > 70%)
- Цветовая индикация влажности (красный < 30%, зелёный 30-70%, синий > 70%)
- Автообновление данных каждые 10 секунд через AJAX 
- Уведомления ВКонтакте о критических значениях 
- Видеонаблюдение через USB-камеру (OpenCV)
- Графики аналитики через ApexCharts 
- REST API для обмена данными между ESP32, браузером и Django 
- Автономная работа в локальной сети без интернета
